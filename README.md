# Agent Skills

English | [简体中文](README.zh-CN.md)

Agent Skills maintained and customized by Brandon.

## Installation

```bash
npx skills add Brandon-Ln/skills --skill batch-grill-me
```

List available skills, or install specifically for Codex:

```bash
npx skills add Brandon-Ln/skills --list
npx skills add Brandon-Ln/skills --skill batch-grill-me --agent codex
```

## Development

Run `pnpm install` to install dependencies and Git hooks. Commits automatically format staged files with Prettier. After changing the hook configuration, run `pnpm prepare`.
